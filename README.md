# MURDERS AT KARLOV MANOR · MKM

> A sphere of **UD0** — the ROOT0 universe / biosphere. Domain: **ARENA**.

MURDERS AT KARLOV MANOR (MKM) — an ARENA Magic: The Gathering sphere: Ravnica's noir whodunit (Feb 2024), curated by basic worth. Pulls all ~279 cards LIVE from Scryfall (card data + the non-foil USD it mirrors from TCGplayer) and buckets them into worth tiers — 🩸 chase ($5+) · staples ($1–5) · role-players ($0.25–1) · bulk (&lt;$0.25) — with a set-value summary (sum / top card / chase count), search, rarity filter, foil-worth toggle, and a Scryfall thumbnail per card. The curation is the tiering + the read applied to REAL numbers (verified live: 279 cards, ~$242 non-foil set value, top Delney, Streetwise Lookout ~$37.05, 15 chase — the surveil-land cycle carries much of the value). Noir palette (detective steel-blue + crime crimson + brass). Honest: prices are a live snapshot and fluctuate daily, an unlisted card shows —; card names &amp; prices are facts, images hot-linked from Scryfall's CDN (sanctioned non-commercial use); an unaffiliated fan price-reference — Magic is © Wizards of the Coast.
